### 3. Meta AI เปิด Mac app คุยกับแอปได้ ใช้ Muse Spark model — [TechCrunch](https://techcrunch.com/2026/08/20/meta-ais-new-mac-app-wants-you-to-talk-to-your-apps/)

นี่คือ **ambient computing** ที่คุยกันมา 15 ปี ลงมาถึง desktop เต็มตัว — screen context + system-wide dictation ทำให้ boundary ระหว่าง app หายไป; interaction model กำลังเปลี่ยนจาก **screen → click** เป็น **intent → action** และการออกแบบ UI ตำราปีนี้จะล้าสมัยเร็วกว่าที่คิด. เชิงโมเดล Muse Spark เป็น multimodal ที่รับ screenshot + audio + text ในหนึ่ง context — จุดที่ต้องจับตาคือ **latency** (เพราะ screen frame ใหญ่กว่า text หลาย order of magnitude) และ **privacy** (screen ทั้งจอเป็น input แปลว่า sensitive data — password prompt, private chat, banking info — ผ่านโมเดลด้วย); Meta ต้อง publish boundary ให้ชัดว่าอะไรอยู่ local อะไรส่ง cloud ก่อนที่ enterprise IT policy จะบล็อกทั้ง app. สำหรับ **โปรแกรมเมอร์ Mac** เตรียม **accessibility label + a11y tree ให้สมบูรณ์** — เพราะ Meta AI + Apple Intelligence + Rewind ใช้ layer นี้อ่านหน้าจอ; app ที่ไม่มี label ถูกต้องจะกลายเป็น "invisible" ให้ AI agent, ลูกค้าเรียกใช้ผ่าน voice ไม่ได้ = หายจาก search result ของยุคนี้ เหมือนหายจาก Google search เมื่อ 15 ปีก่อน.
