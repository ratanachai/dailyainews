### 3. Cloudflare เปิดตัว Kitesurf — browser สำหรับ AI agent — [TechCrunch](https://techcrunch.com/2026/08/07/cloudflare-launches-kitesurf-a-browser-built-for-ai-agents/)

**TechCrunch** รายงานเมื่อ **7 ส.ค. 2026** ว่า **Cloudflare** เปิดตัว **Kitesurf** — cloud-hosted browser ที่ออกแบบสำหรับ AI agent ไม่ใช่ human ผู้ใช้จริง. ไม่มี theme, tab, หรือ extension — แต่จัดการ context window, token cost, และ scalability แทน. ใน internal benchmark ของ Cloudflare เอง Kitesurf ใช้ **CPU ต่ำกว่า Chromium 3.1-3.8 เท่า** และ **memory ต่ำกว่า 4.7-7 เท่า** สำหรับ agent task ทั่วไป (screenshot, HTML extraction). ทีมสร้าง Kitesurf ใน **12 สัปดาห์** รันบน **V8 isolate บน Workers**; ให้ใช้ฟรีระหว่าง beta ผ่านบริการ Browser Run.

architectural principle ในเคสนี้คมมาก — abstraction layer ที่ออกแบบสำหรับ human (DOM, CSS, render pipeline) **ไม่ optimal สำหรับ machine**; agent ต้องการแค่ HTML + screenshot จึงตัด layer ที่เหลือทิ้ง. คำถามต่อไปที่ห้องเรียนควรเปิดคือ "agent-first" แปลว่าอะไรใน stack อื่น (database, API design, network protocol). ในเชิงตัวเลข **3.1-3.8x CPU + 4.7-7x memory** ถ้า reproduce ได้กับ workload จริง (ไม่ใช่แค่ synthetic ของ Cloudflare) จะเปลี่ยน economics ของ **agent-as-a-service** ทันที เพราะ bottleneck ตอนนี้คือ browser cost per session — และคู่แข่ง (Browserbase, AgentQL) จะต้องตอบสนอง. สำหรับทีมที่ทำ scraping / browser automation ด้วย Playwright/Puppeteer — ลอง Browser Run ระหว่าง beta ถ้า workflow ต้องการแค่ HTML/screenshot (ไม่ใช่ complex user interaction หรือ full JS eval); ที่ต้องระวังคือ **lock-in** เพราะรันบน Cloudflare Workers อย่างเดียว ต้อง design layer abstraction ให้ swap กลับ Chromium ได้ถ้าราคาหลุด free tier
